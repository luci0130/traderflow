# Changelog

## 0.1.0 - 2026-08-19

- Added polymorphic image galleries with unique configurable roles.
- Added local and secure remote uploads, WebP optimization, metadata stripping, crop, resize, replace, and drag-and-drop ordering.
- Added signed pending-upload ownership and strict owner-scoped preview and resize resolution.
- Added private-disk temporary URLs, configurable models, tables, morph keys, and panel defaults.
- Added English and Romanian translations and an isolated package test/CI harness.
